# Entregas

A disciplina tem 4 entregas: três ACs e uma entrega final que vale a nota da prova. Cada entrega precisa apresentar **uma funcionalidade nova em vídeo**.

## Cronograma

| Entrega | Data | Cartão do board | Funcionalidade |
|---|---|---|---|
| AC1 | 14/09 | R001 | Cadastro de livros |
| AC2 | 13/10 | R002 | Avaliação de livro — comentários |
| AC3 | 08/11 | R003 | Avaliação de livro — notas |
| Final | 22/11 | R004 | Favoritos |

## O que enviar em cada entrega

**Todos os integrantes** precisam postar no Classroom, mesmo que alguém do grupo já tenha enviado.

Cada entrega deve conter:

- [ ] Lista dos alunos participantes do grupo
- [ ] Link do board do projeto com a lista de funcionalidades
- [ ] Link do GitHub com o código-fonte desenvolvido
- [ ] Vídeo apresentando a funcionalidade desenvolvida no sprint

## Antes de gravar o vídeo

- A funcionalidade da entrega está mergeada na `main`
- Foi criada a tag da entrega (`ac1`, `ac2`, `ac3`, `final`) — assim o professor consegue ver exatamente o código que aparece no vídeo
- O cartão correspondente está concluído no board
